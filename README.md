# Turnul Alb — landing page concept

Адаптивный лендинг на HTML, CSS и JavaScript. Откройте index.html в браузере. Для локального HTTP-просмотра: `python -m http.server 4173 --bind 127.0.0.1` из папки проекта.

Включены: три зала с переключением, галерея, мобильная навигация, FAQ и формирование сообщения в WhatsApp. Форма не бронирует дату и не отправляет данные автоматически: пользователь самостоятельно отправляет подготовленное сообщение менеджеру. CRM и проверка календаря не подключены.

Фотографии загружены с turnulalb.md, логотип предоставлен заказчиком. Вместимость и количество номеров взяты с исходного сайта. Перед публикацией согласуйте тексты, фото и контакты. Шрифты Bodoni Moda, Cormorant Garamond и Manrope сохранены локально. Анимации: раскрытие занавеса, маски фотографий, проявление слов, параллакс и сцена при прокрутке. Lenis взят из предоставленного референса Persona. Движение можно отключить кнопкой внизу экрана; учитывается системная настройка reduced motion. Концепт не гарантирует конкретный рост конверсии; результат оценивается по аналитике после запуска.
